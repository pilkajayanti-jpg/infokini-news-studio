# InfoKini News Studio V2

New Android studio app for newsroom production, TV-style graphics, editing, AI-assisted editorial work and live-stream preparation.

- Package: `id.infokini.news`
- Minimum Android: 9 (API 28)
- Visual identity: navy, red, white and cyan
- Offline-first local production with optional online services
- AI Redaktur included; **Reporter AI intentionally excluded**
- Editorial approval required before publication/export/broadcast of AI-assisted news

## Build
Use GitHub Actions workflow **Build InfoKini News Studio V2 APK** on branch `studio-v2`. Download the artifact `InfoKini-News-Studio-V2-APK` after a successful run.

## Important status
This branch begins the V2 foundation. The current milestone provides a new Compose app shell and module navigation/preview scaffolding. Live RTMP, full video timeline/export, photo layer editor, AI backend, cloud services and production integrations are not yet complete. Do not treat the initial shell as a finished application.

See `docs/INFO-KINI-NEWS-STUDIO-V2-SPEC.md` for the approved scope and acceptance milestones.
