# InfoKini News Studio

**Founder / Penggagas:** Wandi Azis  
**Product Owner:** Wandi Azis  
**Merek:** infokini.news  
**Platform:** Android

InfoKini News Studio adalah proyek aplikasi produksi konten berita digital yang dikembangkan bertahap.

## Fitur yang sudah ada pada source saat ini
- Studio berita dasar dengan judul, lokasi, dan running text.
- Label LIVE (indikator tampilan, bukan koneksi siaran langsung).
- Pemilihan foto/video dan pratinjau media.
- Simpan dan muat draf lokal untuk judul, ticker, dan lokasi.
- Bagikan teks konten melalui aplikasi Android.
- Pembacaan naskah bahasa Indonesia menggunakan TextToSpeech Android.
- Mode skor sepak bola manual dan status pertandingan.
- Editor draf berita olahraga manual, tautan sumber, status verifikasi, dan TTS.

## Fitur yang masih dalam pengembangan
- Template studio TV lengkap, overlay grafis, logo dan lower-third.
- Editor foto dan editor video penuh (potong, gabung, transisi, audio, subtitle).
- Rendering dan ekspor MP4 final.
- AI Reporter / AI Redaktur dengan pengambilan berita aktual, sumber terverifikasi, pemeriksaan fakta, dan persetujuan redaktur.
- Data skor langsung, logo tim/kompetisi, statistik pertandingan, dan grafis siaran.
- Integrasi siaran langsung YouTube, TikTok, dan Facebook.
- Modul iklan/promosi UMKM dan konfigurasi layanan pendukung.

## Catatan penting
Build APK yang berhasil hanya membuktikan source dapat dikompilasi. Itu bukan bukti bahwa seluruh fitur telah tersedia atau lolos uji perangkat. Integrasi API membutuhkan layanan dan kredensial resmi; jangan memasukkan API key rahasia ke source code publik.

Aplikasi belum boleh dinyatakan sebagai versi lengkap atau siap rilis Play Store sebelum fitur di atas selesai, diuji, dan dokumentasi privasi serta kebijakan aplikasinya disiapkan.
